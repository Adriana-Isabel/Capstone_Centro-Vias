# Tests

This directory contains tests used to verify the functionality, reliability, accessibility, and quality of the Centro Vías website.

## 🎯 Purpose

Testing helps ensure that the system meets its functional and non-functional requirements and behaves as expected across different scenarios.

## 🧪 Types of Testing

Testing may include:

### Unit Testing

Tests individual functions, components, or modules independently.

### Integration Testing

Tests how multiple components or services work together.

### End-to-End Testing

Tests complete user workflows from beginning to end.

### API Testing

Verifies that backend endpoints behave correctly.

### Database Testing

Verifies database operations, relationships, constraints, and data integrity.

### Accessibility Testing

Checks that the website can be used effectively by people with different accessibility needs.

### Usability Testing

Evaluates whether users can understand and navigate the website effectively.

### Responsive Testing

Verifies that the website functions correctly across different screen sizes and devices.
