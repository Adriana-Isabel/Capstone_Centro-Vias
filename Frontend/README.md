# Frontend

This directory contains the client-side code for the Centro Vías website.

The frontend is responsible for the website's user interface, navigation, content presentation, accessibility, responsiveness, and interaction with the backend services.

## 🎯 Responsibilities

The frontend should:

* Provide a clear and intuitive user experience.
* Present information about Centro Vías and its activities.
* Provide access to participant admissions information.
* Provide volunteer and donation information.
* Provide contact and organization information.
* Communicate with backend services when necessary.
* Follow accessibility and responsive-design principles.
* Maintain a consistent visual identity throughout the website.

## 📁 Structure

The structure of this directory will depend on the framework selected for the project.

A possible structure is:

```text
frontend/
├── public/
├── src/
│   ├── components/
│   ├── pages/
│   ├── assets/
│   ├── styles/
│   ├── services/
│   └── utils/

└── README.md
```

## ♿ Accessibility

Frontend development should consider:

* Keyboard navigation
* Semantic HTML
* Alternative text for images
* Appropriate color contrast
* Readable typography
* Clear navigation
* Responsive layouts
* Descriptive buttons and links
